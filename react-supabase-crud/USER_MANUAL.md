# KKK Group Digital Billboard — User Manual

## Before you begin

Create an account and sign in. You will need a video file, your requested booking dates, daily run times, and a payment reference number to submit a booking.

## Create a booking

1. Select **Create New Task**.
2. Enter a task title and upload the video advertisement.
3. Set the **Start date**, **End date**, and one or more **Daily run times**.
4. Select either a custom plan or a package plan.
5. Choose a payment method, enter the payment reference number, and tick the payment confirmation box.
6. Select **Submit** to create the booking.

The system checks that the requested date range is not already booked. If any date in the range is unavailable, select different dates before submitting.

## Payment status — important

The payment options currently displayed in the application (PayMongo, GCash, Maya, and bank transfer) are **not yet connected to a live payment service**. Selecting a method does not process, verify, or transfer payment.

For now, the payment reference number and confirmation checkbox are recorded with the booking as a payment-submission record. Payment must be verified manually by an administrator before it should be treated as completed.

Do not rely on the application's “paid” confirmation alone as proof that a payment was received.

## View a booking

Your bookings appear in the task list with their date range, daily run times, selected plan, video link, and payment reference.

## Administrator guide

Administrators can use **Bookings Calendar** to see each booking on every day of its reserved date range. Select a calendar day to view the customer, plan, price, schedule, and daily run times.

Administrators should manually confirm payment using the payment provider or bank before scheduling the advertisement for delivery.
